> **For agentic workers:** REQUIRED SUB-SKILL: superpowers:subagent-driven-development. Steps use `- [ ]`.

**Goal:** Build every role's interface (doctor, nurse, admin, patient) in `web/` from the Claude Design handoff, pixel-faithful, on mock data that matches `docs/contracts/api.md`, so it switches to the real API when Wali's backend lands. Faouzi asked for it on 2026-10-06 ("build the interfaces of each user").

**Branch:** `faouzi/web-ui` from `main` (PR against `main`).

**Design source (read-only, git-ignored, never commit it):** `claude design output/healthcare-ui-mockups/project/`
- `Ward Doctor.dc.html`, `Ward Nurse.dc.html`, `Ward Admin.dc.html`, `Ward Patient.dc.html`: each holds several screens, one `<section data-screen-label=…>` per screen, with the route in a `<code>` tag next to the label.
- `Sidebar.dc.html` (role nav), `Waitlist.dc.html` (shared ranked waitlist).
- `shots/*.png`: reference screenshots.
- `support.js` is the prototype runtime. Do not port it.
- Format: the markup inside `<x-dc>` uses inline styles. `{{ x }}` binds to values computed in the `<script type="text/x-dc">` class `renderVals()`. `<sc-for list as>` is a loop, `<sc-if value>` a conditional, `<dc-import name=… prop=…>` embeds another file, and `style-hover` is a hover style. The script's arrays are the sample data.
- Each file's header paragraph and its "States" section describe the demo toggles and the loading, empty, error, reconnecting, "AI unavailable" and no-device states.

## Global Constraints

- Next.js 16 App Router, React 19, TypeScript strict, in `web/`. No new runtime dependencies. Fonts via `next/font/google` (Fraunces 400/500/600 with the `opsz` axis; Public Sans 400/500/600/700).
- **Styling ruling:** CSS Modules plus global design tokens in `web/src/app/globals.css`, not Tailwind. The design is exact inline CSS, Tailwind is not installed, and CLAUDE.md is updated in Task 1. Put every repeated colour into a CSS custom property, named after its role (`--ink: #0F2D44`, `--teal: #0B8A96`, `--paper: #FCFDFD`, `--canvas: #F3F6F7`, `--line: #D8E1E4`, NEWS2 level colours, and so on), and use the exact hex values from the design. Keep the keyframes `wardPulse`, `wardShimmer` and `wardBlink`.
- **Pixel fidelity:** reproduce sizes, spacing, radii, font sizes and weights, and colours exactly. The design frame is 1440 px: the sidebar is 248 px and `main` fills the rest. The app itself fills the viewport, so don't hard-code the 1440 frame. Where the design shows a tablet (1024 px) or phone frame, honour it with a media query.
- **Data:**
  - Types in `web/src/lib/types.ts` mirror `docs/contracts/api.md` (IDs like `p-0001`, ISO timestamps, AI fields `ai_suggested`, `source: "model"|"rules"|"llm"`, `human_confirmed_by`).
  - Mock fixtures in `web/src/mocks/` are copied from the design scripts' sample data. They are synthetic; never add real people.
  - Components read data through `web/src/lib/api.ts`, which returns the fixtures when `NEXT_PUBLIC_USE_MOCKS=1` (the default when unset) and otherwise calls `NEXT_PUBLIC_API_URL` with the paths in `api.md`.
  - UI-only derived values (colours from NEWS2, labels) are computed in the components, not stored in the fixtures.
- **AI label mapping:** the design says "AI suggestion · Model" or "AI suggestion · Rules fallback". Map from `source`: `model` → "Model", `llm` → "Model", `rules` → "Rules fallback". Keep "needs review" until `human_confirmed_by` is set (locked rule). The patient must never see an AI urgency score.
- **Demo states:** reproduce the design's Tweaks toggles with query params on any page: `?ai=rules` (AI unavailable), `?live=0` (reconnecting banner and paused values), `?state=loading|empty|error` where the design's "States" section shows those for that screen. One shared hook, `useDemoFlags()`.
- **Interactivity:** implement what the design scripts implement (toggles, forms, toasts, live tick, review/undo, waitlist actions), against local state plus the api.ts mock functions. No real network in mock mode.
- **Accessibility:** keep the design's `role`, `aria-*` and `dir="auto"` attributes. Arabic names render right-to-left.
- **Copy:** use the design's text verbatim, including the honesty lines ("Values are simulated for this prototype").
- Verify with `cd web && npm run typecheck && npm run build` (both must pass). Don't commit `.next/` or `node_modules/`.
- Only edit `web/` and the lines of `CLAUDE.md` named in Task 1. Commits are Conventional Commits with no Co-Authored-By and no "Generated with" line.
